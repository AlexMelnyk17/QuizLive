Необіхідні інструменти для запуску проєкту:
Visual Studio 2022 (з компонентом "ASP.NET and web development").
Node.js (бажано актуальної LTS версії: 20.x або 22.x). 
Крок 1. Клонування репозиторію
git clone <сюди-вставити-посилання-на-github>
Крок 2. Встановлення залежностей фронтенду
Для встановлення залежностей фронтенду відкрийте термінал у папці QuizLive/QuizLive.Client і виконайте команду:
cd QuizLive/QuizLive.Client
Запустіть встановлення пакетів:
npm install
(Дочекайтеся завершення. Має з'явитися папка node_modules всередині QuizLive.Client).
▶️ Крок 3. Запуск проєкту
Відкрийте файл QuizLive.sln у Visual Studio 2022.
Переконайтеся, що зверху на панелі обрано запуск бекенд-проєкту (зелена кнопка Play з написом QuizLive.Server).
Натисніть Play (або F5).
